# PSHR Architecture v0.20 (First Public Release Candidate)

Released September 29, 2026. Built on v0.19 of September 15, 2026.

## What is new

- Section 2.17, The Environment Folder: `_environment/` holds how a copy of the record is set up: governing jurisdiction and the active law-pinned set with its change history; record settings (age of majority, official copy, language and locale, data residency); the AI routing map; the model registry; per-model cost and quality tallies; pending routing proposals; cryptographic configuration identifiers; and implementation identity. Setup facts, never rules, and never key material.
- Governed model selection: the person selects the model serving each task type; the implementation must inform the person when a better or updated model clears the evidence threshold; a change of model is adopted only by the person's recorded decision and is never automatic (Sections 7.1 and 7.3).
- Context files carry the routing map and the arriving model's own track record (Section 6.1).
- Appendix A adds environment folder, routing map, model registry, and routing proposal. Appendix B adds the `_environment` row. Appendix C indexes AI model selection, jurisdiction setting, and model registry.
