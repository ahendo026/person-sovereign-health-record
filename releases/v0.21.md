# PSHR Architecture v0.21 (Public Release Candidate)

Released October 25, 2026. Built on v0.20 of September 29, 2026.

## What is new

- Folder 06 is now `06-results`, a plain-language name with FHIR Observation kept as the file format inside, divided by kind of fact rather than by source: `labs/`, `labs-reproductive/` (its own sharing boundary), `vitals/`, `device-readings/` (Device Readings, the continuous data of Section 2.6), and `implanted-devices/` (Implanted Devices, formerly the implants list).
- Section 2.18, Laboratory Results: one entry per result and one report entry per panel; LOINC codes and UCUM units with the as-read name, unit, and range retained; one series per test from every source; a conforming implementation never guesses a code (unresolved results are filed, flagged, and kept off trends until confirmed); flags are the source's; corrections are new entries that supersede, never edits in place; disagreements between sources are shown, never silently resolved; file naming and path constraints stated in conformance language.
- Section 2.5 names the record-time element: every entry carries record time in the extension `https://precisionhealthventures.com/fhir/StructureDefinition/pshr-record-time`, set once and never changed.
- Section 2 states that originals in folder 09 and filed entries are write-once.
- Section 6 defines the healthcare harness, the boundary every model passes through, and says open-weight where it said open-source.
- Appendix A adds record-time element, LOINC, UCUM, panel, Device Readings, and healthcare harness. Appendix B carries the `06-results` row. Appendix C updates eighteen entries and adds device readings, lab panel, and reproductive health lab.
