# PSHR Architecture v0.22 (Public Release Candidate)

Released October 31, 2026. Built on v0.21 of October 25, 2026.

## What is new

- Section 6.2, The Precision Profile and Governed Learning. The Precision Profile is a continuously updated working picture of one person's health state that a model can reason over without reading the full record each time. A conforming implementation derives it by deterministic code from filed entries, never by a model; every value names the entries it was computed from; the profile is regenerable from the record tree; it is computed where the record lives and leaves custody only under a grant; and it excludes exogenous data (air quality, weather, neighborhood and social factors) in this version.
- Governed Learning is the comparison of one profile against many others to find clinically meaningful patterns, as privacy-preserving analysis under the person's authorization and governed by Earned Autonomy. It happens only under an explicit per-purpose authorization recorded in the consent engine, is stated as direction, has trial matching for research as its first application, is never clinical decision support, and has no comparison method standardized in this version. No model holds profile state.
- Section 6 points to the new section.
- Section 2.17 cross-references Section 5.1 at its first use of sealing.
- Section 2.18 lists the seven extension names used beside the record-time element under the PHV base URL: `pshr-replaces`, `pshr-source`, `pshr-extraction`, `pshr-read-class`, `pshr-confidence`, `pshr-needs-confirmation`, and `pshr-calculation`.
- Appendix A adds Precision Profile, Governed Learning, and sealed record.
